The Sensing Problem

When the direct path disappears, conventional sensing fails.

In urban environments, industrial facilities, and complex terrain, physical obstacles block direct signal paths between sensor and target. Traditional radar and LiDAR systems lose contact when line-of-sight is interrupted.

Signal attenuation, multipath fading, and limited NLOS coverage compound the problem — reducing detection reliability precisely when it matters most: in autonomous navigation and safety-critical sensing.

Conventional System

Signal Diversity

One system. Two paths.

The proposed RIS-aided system simultaneously exploits both a direct antenna path and an RIS-assisted reflected path, combining signals to achieve coverage and detection even when one path is blocked.

Antenna 1 — Direct Path

Line-of-Sight Transmission

The first antenna provides direct signal propagation between transmitter and receiver. When the environment is unobstructed, this path delivers the primary detection signal with minimal delay and attenuation.

Antenna 2 — RIS-Reflected Path

Intelligent Reflection

The Reconfigurable Intelligent Surface reflects and redirects signals around obstacles, providing coverage in non-line-of-sight scenarios. Phase control over RIS elements enables beam steering without active RF components.

LOS vs NLOS

Coverage in both environments.

The dual-antenna configuration ensures that signal diversity supports reliable detection regardless of whether a direct line-of-sight exists.
