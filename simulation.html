Project Simulation Reference Disclosure

This page is an interactive technical visualization developed to illustrate the electromagnetic principles and design specifications of Project 22EC711 (RIS-Aided Dual Antenna for Obstacle Detection). All S-parameter curves, wavefront fields, and phase states are visual reference representations generated from the project's design parameters (8–12 GHz band, 10 GHz design point, FR-4 substrate, S11 < −30 dB, S21 ≈ −3 dB) and are not real-time CST Microwave Studio solver outputs.
